## Critical Issues Identified & Resolved

### Issue #1: mDNS Hostname Resolution (ACTIVE)
**Problem:** `midnightrider.local` resolves to link-local address (169.254.119.236) instead of WiFi IP (192.168.1.167)
**Root Cause:** Avahi daemon binding to wrong interface (likely due to hotspot interface present)
**Workaround:** Use direct IP instead of hostname
**Temporary Solution:** iPad should use `http://192.168.1.167:5000` instead of `http://midnightrider.local:5000`
