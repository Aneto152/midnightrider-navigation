# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in Midnight Rider Navigation,
please report it responsibly:

1. Do NOT open a public GitHub issue for security vulnerabilities
2. Email the maintainer directly (see profile)
3. Include: description, steps to reproduce, potential impact
4. You will receive a response within 72 hours

## Scope

- Signal K configuration and plugins
- InfluxDB/Grafana integration
- Portal server (Python HTTP server)
- Regatta planning service
- Docker Compose configuration

## Out of Scope

- Third-party services (InfluxDB, Grafana, Signal K themselves)
- Physical hardware security

## Disclosure Policy

We follow responsible disclosure. After a fix is deployed,
we will acknowledge the reporter in the release notes
(unless anonymity is requested).
